# 🕒 Calculadora de Ponto com Tolerância

Este projeto foi desenvolvido para automatizar o cálculo das horas de trabalho, considerando as margens de tolerância. Com esta ferramenta, consigo saber a hora exata em que posso sair do trabalho sem ser penalizado, garantindo o cumprimento da jornada de forma precisa.

## 📝 Descrição

O sistema processa os registos de entrada e saída e aplica as regras de tolerância configuradas (atualmente ajustadas para 15 minutos). É especialmente útil para quem precisa de gerir horas extraordinárias e garantir que o tempo de saída está dentro do esperado pela legislação ou normas da empresa.

## 🚀 Funcionalidades

- **Cálculo Automático:** Processamento de horários de entrada, almoço e saída.
- **Gestão de Tolerância:** Ajuste dinâmico para calcular o limite exato de saída.
- **Interface Intuitiva:** Desenvolvido com Streamlit para facilitar a utilização.
- **Leitura de Dados:** Suporte para extração de dados a partir de ficheiros PDF.

## 🛠️ Tecnologias Utilizadas

- **Python**: Lógica principal de cálculo.
- **Streamlit**: Interface web e visualização de dados.
- **Pandas**: Manipulação e tratamento de dados temporais.

## ⚙️ Como Utilizar

1. Introduz os teus horários de registo de ponto.
2. O sistema aplicará automaticamente a tolerância de 15 minutos.
3. Visualiza o horário exato de saída permitido e o saldo de horas do dia.
